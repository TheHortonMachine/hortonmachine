# GeoFrame

The modules of the **GeoFrame** folder of the Spatial Toolbox prepare the data for, and run, the hydrological models of the GEOframe modelling system:

- [ERM (Embedded Reservoir Model)](erm/index.md): the water budget of a basin split into sub-basins, each one modelled as a set of connected reservoirs, from the data preparation to the calibration and the simulation of the discharge.
