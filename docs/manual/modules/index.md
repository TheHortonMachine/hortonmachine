# The modules

This section describes the most important processing modules of the HortonMachine: those used the most, and the complex models that need more explanation than the short help shown in the [Spatial Toolbox](../apps/spatialtoolbox.md).

The modules are grouped in the same folders as in the Spatial Toolbox. For each module, the description, the parameters and the references are generated from the documentation inside the module itself, the same one shown in the Spatial Toolbox.
