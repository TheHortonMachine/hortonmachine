# LasMerger

LasMerger merges all the LAS files of a folder into a single file, as the tiles in which surveys are delivered.

## Example

The pieces of the example of [LasSplitter](lassplitter.md) merged back into a single file, outside of their folder:

```{literalinclude} ../examples/hm/lasmerger.groovy
:language: groovy
```

The merged file has the 33,410 points of the sample survey and its crs.
