# CodeMirror 5

The code editor of the cells of the notebooks, served by the server under `/static/notebook/`,
so that the notebooks work without internet.

- Version: 5.65.18, MIT license (see `LICENSE.txt`).
- Source: the npm package `codemirror@5.65.18`, checked against its published sha512 integrity.
- Files: `lib/codemirror.js`, `lib/codemirror.css`, `mode/groovy/groovy.js`, `mode/markdown/markdown.js`,
  `addon/edit/matchbrackets.js`, `addon/edit/closebrackets.js`, unchanged.
